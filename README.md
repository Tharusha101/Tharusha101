## 👨‍💻 About Me

Electrical & Electronic Engineering student building at the intersection of **AI, developer tooling, and control systems**. I work primarily in **Python** (with MATLAB for control and simulation work), and I care about the full engineering picture — not just training a model, but the tooling, data pipelines, and systems thinking that make it reliable.

- 🤖 Building **AI tooling, code-generation, and synthetic-data** projects
- 🧠 Exploring **agentic systems, MCP servers, and computer vision**
- 🎮 Hands-on with **reinforcement learning** — from DQN agents playing DOOM to neural-net Pong
- ⚙️ Strong **control systems** foundation — inverted pendulums, reaction-wheel balancers
- 🐧 Daily driver: Arch Linux (*I use Arch, btw*)

**Open to:** AI/ML engineering internships · Software engineering roles · Open source collaboration · Research-adjacent engineering work

## 🚀 Featured Projects

<details>
<summary><b>⭐ StarNet — Celestial Navigation with Deep Learning</b></summary>
<br/>

A convolutional neural network for celestial navigation: given an image of the night sky, identify the star field and derive orientation — no GPS required.

| | |
|:--|:--|
| **Stack** | Python · PyTorch · CUDA · NumPy · OpenCV |
| **Scale** | Synthetic star-field dataset with GPU-accelerated training pipeline |
| **Performance** | Custom CNN architecture iterated through systematic root-cause analysis of training failures |
| **Security** | Fully offline inference — zero external positioning dependency |
| **Impact** | GPS-independent attitude estimation from a single camera input |
| **Repository** | In development |

StarNet tackles the classic "lost in space" problem with modern deep learning, covering the full ML lifecycle — dataset synthesis, architecture design, training diagnostics, and CUDA-optimized experimentation on local hardware.

</details>

<details>
<summary><b>🎮 DOOM-DDQN — Double Deep Q-Network Agent for DOOM</b></summary>
<br/>

A reinforcement-learning agent that learns to play DOOM from raw pixels using a Double DQN.

| | |
|:--|:--|
| **Stack** | Python · PyTorch · VizDoom · Gym-style environment loop |
| **Scale** | Frame-stacked pixel observations, experience replay training |
| **Performance** | Double Q-learning to reduce value over-estimation vs. vanilla DQN |
| **Security** | Fully local training and evaluation |
| **Impact** | End-to-end RL pipeline: environment wrapping, replay buffer, target networks, evaluation |
| **Repository** | [github.com/Tharusha101/DOOM-DDQN](https://github.com/Tharusha101/DOOM-DDQN) |

Demonstrates the core deep-RL toolkit — epsilon-greedy exploration, replay memory, and periodically synced target networks — applied to a visually complex 3D environment.

</details>
